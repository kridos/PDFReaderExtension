Read aloud

Open a PDF to set a reading range.

Pick what to read from the list, then type the word or phrase it needs — or select one on the page and press Use selection. The first match inside the page range is used, so the whole section never needs highlighting. Leave To page empty to keep reading to the end of the document, and From page empty to start at the beginning. Dimmed fields are not used by the selected option.
